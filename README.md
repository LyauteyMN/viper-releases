# Viper

Instaladores e atualizações do Viper, monitor de hardware para Windows.

- **Viper-Setup-x.y.z.exe**: instalador. O app instalado se atualiza sozinho a partir desta página.
- **Viper-Portable-x.y.z.zip**: versão portátil (pendrive). Configurações e histórico ficam na pasta `dados` ao lado do exe.

Baixe a versão mais recente em [Releases](https://github.com/LyauteyMN/viper-releases/releases/latest).
